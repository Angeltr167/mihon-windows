# Ronin 1.0.22 para Windows

Se completan las traducciones al español de biblioteca, actualizaciones,
historial, fuentes, extensiones, descargas y ajustes de seguimiento. Incluye
botones, campos de búsqueda, menús, estados, recuentos, fechas y la fuente local.
Las etiquetas siguen el idioma elegido en Ajustes → General.

Los nombres y textos originales de mangas, capítulos, servicios y extensiones
se conservan. Los mensajes recibidos directamente de servicios externos pueden
mantener su idioma original.

El instalador conserva el perfil existente y las funciones de copia de seguridad
y preferencias de la versión 1.0.21. Cierra Ronin antes de instalar esta versión.

Validación: pruebas de escritorio, revisión de formato y arranque de la
distribución empaquetada con un perfil temporal independiente.
